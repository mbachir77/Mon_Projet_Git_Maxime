\## Règles de fonctionnement de l'équipe

\- \*\*Branches\*\* : Toute nouvelle fonctionnalité doit être créée sur une branche spécifique (ex: `feature-nom`).

\- \*\*Commits\*\* : Nous utilisons la convention Angular (`feat:`, `fix:`, `docs:`, `chore:`).

\- \*\*Merge\*\* : Le passage sur la branche `main` se fait uniquement après résolution des conflits en local.

\- \*\*Gestion de projet\*\* : Le tableau Trello doit être mis à jour après chaque commit important.
